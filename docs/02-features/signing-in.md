# Signing in

## Sign in

1. Open the app and enter your work email.
2. Select **Send OTP**. A 6-digit code is emailed to you.
3. Enter the code. You are signed in as soon as the last digit is typed.

You stay signed in on that device for 30 days.

## If something goes wrong

- **"User is not added in the system"**: your email is not on the team list. Ask someone
  with access to add you from the **Users** page.
- **The code did not arrive**: check spam, then select **Resend OTP**. You can request a
  new code once a minute.
- **"Invalid OTP"**: the code was mistyped or has expired. Codes last 10 minutes and allow
  3 attempts; request a new one if needed.

## Sign out

Select your name in the top-right corner, then **Logout**.
