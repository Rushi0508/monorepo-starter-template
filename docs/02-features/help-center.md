# Using the Help Center

Open **Help Center** in the sidebar. Guides are grouped by topic on the left, and each page
lists its sections under "On this page".

## Search

Press **⌘K** (or **Ctrl+K**), or select the search bar at the top, to search pages, guides
and training videos. Matching text in a guide is shown under its title.

## Download a page

On any guide, select the download icon next to the title and choose PDF, Word or Markdown.
Use this to share a page with someone who does not have access.

## Training videos

Select **Training videos** at the top of the Help Center sidebar.

- Select a video to play it in place.
- Select **Add Video** to add a Loom or Tella walkthrough with a title and an optional
  description.
- Use the **⋮** menu on a video to edit or delete it.
