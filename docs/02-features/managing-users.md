# Managing users

Open **Users** in the sidebar to see everyone who can sign in. Use the search box to find
someone by name or email.

## Add a user

1. Select **Add User**.
2. Enter their name and work email.
3. Select **Add User**. They can sign in straight away with that email.

## Rename a user

Select the pencil icon on their row, change the name, and select **Save Changes**. The
email cannot be changed.

## Remove a user

Select the bin icon on their row and confirm. They are signed out everywhere and can no
longer sign in. You cannot remove yourself.
